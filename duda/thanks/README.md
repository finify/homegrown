# Special thanks page (/thanks-to)

## Finding it in the editor
In the editor the page is called **Acknowledgements**, not "thanks-to" (that's only its URL), and it isn't in the main menu.
- Open **Pages** in the left panel and look for **Acknowledgements**. Hidden pages are listed there too, often lower down or under a "hidden pages" heading.
- If it's still hard to spot, use the page search box at the top of the Pages panel.

## Install
1. Open the Acknowledgements page, then **Developer Mode** (the page HTML).
2. Select all its HTML, delete it and paste `after/thanks.html`.
3. Save, preview and **Publish**:
   `https://websitebuilder.123-reg.co.uk/site/0432dc74/thanks-to?preview=true&insitepreview=true&dm_device=desktop` (change `desktop` to `tablet` or `mobile`).

There's no stylesheet to link: the styles are in `base.css`, already linked site-wide.

## What's on the page
- **Header:** "Our supporters", a large "Special thanks" title and the page's own thank-you text.
- **Team photo:** the photo that was the old banner, now shown in full with rounded corners.
- **How they help:** one card each for the four supporters the old page described: Sunderland City Council, Sunderland CLLD, Coalfields Regeneration Trust and Barclays. Each card has the logo (never cropped), name and the old page's text, lightly tidied.
- **With thanks also to:** the three logos the old page showed without any text (Big Issue Invest, Social Investment Business, The National Lottery Community Fund), each with its name.
- **Closing panel:** "Interested in supporting our work?" with a "Get in touch" button to the Contact page.

Every block is a normal Duda text or image widget. To add a supporter, copy a card or a logo tile in the editor and change the logo, name and text.

## Words: what changed

- One sentence dropped from the intro: "Our unique development ensures that we have the very best support." It didn't read clearly. Add it back in the editor if you want it.
